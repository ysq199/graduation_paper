## 5. 当前算法逻辑

```text
1. 根据候选视点的有效视场半径，估计每个视点能覆盖的叶片表面点。
2. 对高曲率、边界和粗糙区域赋予更高权重，形成加权覆盖模型。
3. 采用带运动代价惩罚的贪心覆盖策略选择视点。
4. 对选中的视点序列进行 2-opt 路径短化。
5. 输出有序拍照路径及覆盖率、路径代价等指标。
```

## 6. 可写进论文的表述

```text
在候选视点集合构建完成后，本文进一步建立面向缺陷检测任务的加权覆盖模型，将叶片表面点的局部曲率、ROI边界显著性和粗糙度作为覆盖权重，以突出叶尖、进/排气边等关键区域的检测优先级。在此基础上，提出一种结合新增覆盖收益与相邻视点运动代价的贪心视点选择方法，并采用2-opt策略对选中视点序列进行路径短化，从而在保证关键区域覆盖的同时降低机器人末端拍照路径长度。
```

## 7. 后续强化学习接口

当前贪心策略可以作为强化学习实验的基线。强化学习环境可以定义为：

```text
状态：已覆盖表面点比例、当前位置、剩余候选视点特征。
动作：从未访问候选视点中选择下一个视点。
奖励：新增加权覆盖收益 - 运动代价 - 重复覆盖惩罚。
终止：达到目标覆盖率或达到最大拍照次数。
```

## 10. 50k Maskable PPO 阶段性结果

本轮 50000 timestep 训练记录已整理到：

```text

```

同样使用 5000 个表面点、最多 80 个视点时，Maskable PPO 在覆盖指标上已经小幅超过贪心 baseline：


但 PPO 路径代价仍较高：


下一轮建议提高运动代价惩罚或增加局部邻近动作偏好，使 PPO 在保持覆盖优势的同时缩短路径。

## 11. 路径约束增强调参结论

已完成 `reward_motion_scale = 0.55` 与 `0.75` 两轮 50000 timestep 训练，记录见：

```text
Maskable_PPO_实验记录.md
```

结果表明，单纯增大运动代价惩罚可以缩短 PPO 路径，但会明显牺牲覆盖率：

```text
PPO 0.35: weighted_coverage_ratio = 0.7153, path_cost_after_2opt = 1038.3672
PPO 0.55: weighted_coverage_ratio = 0.6699, path_cost_after_2opt = 855.2276
PPO 0.75: weighted_coverage_ratio = 0.6929, path_cost_after_2opt = 919.3200
```

下一步不建议继续单纯提高 `reward_motion_scale`，而应加入局部邻近动作偏好：保持覆盖收益权重不变，只对过远跳转动作施加额外惩罚。

## 12. 局部邻近动作偏好结果

已新增局部远跳惩罚参数：

```text
--reward-local-jump-threshold
--reward-local-jump-scale
```

推荐的当前折中配置：

```cmd
--reward-motion-scale 0.35 --reward-local-jump-threshold 0.55 --reward-local-jump-scale 2.0
```

50000 timestep 结果：

```text
PPO coverage-first: weighted_coverage_ratio = 0.7153, path_cost_after_2opt = 1038.3672
PPO local-jump threshold 0.55 scale 2.0: weighted_coverage_ratio = 0.7099, path_cost_after_2opt = 1001.2988
Greedy baseline: weighted_coverage_ratio = 0.7036, path_cost_after_2opt = 770.9113
```

阶段结论：局部邻近偏好能在保持高于贪心的加权覆盖率时，降低覆盖优先 PPO 的路径代价；但路径长度仍未达到贪心基线水平。
