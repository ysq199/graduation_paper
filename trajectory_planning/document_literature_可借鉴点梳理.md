# document_literature 可借鉴点梳理

## 总体判断

这批文献对第一篇论文有明显参考价值，但它们主要集中在加工、打磨、缝纫、上色等任务中的轨迹规划，基本没有直接解决“内窥镜缺陷检测前的主动拍照视点选择”问题。因此，建议采用“借鉴几何轨迹生成方法，创新强化学习主动视点决策”的策略。

第一篇论文可以形成如下定位：

```text
已有研究：视觉定位 / 轮廓提取 / 曲面重构 / 离线轨迹生成 / 曲率自适应步长
本文工作：外部视觉粗定位 + 多部位候选视点模板 + Maskable PPO主动视点选择 + 质量反馈补拍
```

## 1. 最值得借鉴的文献

### 1.1 基于视觉定位与轨迹规划的机器人打磨工作站

可借鉴点：

1. 用视觉定位替代人工示教，解决工件定位困难和轨迹示教繁琐问题。
2. 使用模板匹配实现机器人定位引导。
3. 使用边缘提取、轮廓拟合和网格法判断待处理区域。
4. 结合机器人坐标转换完成离线轨迹规划。

迁移到本项目：

1. 外部相机负责转子叶片粗定位和目标叶片识别。
2. 叶片待检区域可用边缘/轮廓/区域网格表示。
3. 视觉坐标到机器人坐标的转换可作为第一篇的系统基础。

不能直接照搬的地方：

1. 该文是打磨轨迹，不是拍照视点规划。
2. 其轨迹主要服务材料去除，本文轨迹服务图像质量和缺陷检测。

### 1.2 基于三维点云的风电叶片飞边残留量检测与机器人打磨路径规划

可借鉴点：

1. 采用三维点云获取叶片几何信息。
2. 利用法向量差分分割叶片局部特征。
3. 使用B样条曲线进行曲面重构。
4. 使用等截平面法生成路径曲线。
5. 使用曲率差值法计算自适应步长。
6. 通过手眼标定完成目标点到机器人路径的转换。

迁移到本项目：

1. 叶盆、叶背等曲面区域的候选视点间距可以由曲率决定。
2. 进气边、排气边等边缘区域可以用法向变化或曲率突变辅助定位。
3. 内窥镜拍照点可以沿等截面线或等弧长线离散生成。
4. 手眼标定和坐标转换是外部相机到末端内窥镜映射的必要基础。

最适合写进本文的方法点：

```text
基于曲率的候选视点自适应采样
```

### 1.3 近净成形叶片重构曲面刀具轨迹自适应规划

可借鉴点：

1. 专门针对航空发动机叶片进/排气边区域。
2. 关注重构曲面曲率变化大、边界不齐、局部不光顺等问题。
3. 通过光顺偏置曲面生成光顺刀心轨迹。
4. 以残留高度和曲率半径关系确定路径疏密。
5. 通过偏差验证迭代增加截面线。

迁移到本项目：

1. 进气边、排气边的内窥镜拍照路径可采用“偏置曲线/偏置曲面”思想。
2. 相机工作距离本质上就是沿局部法向进行安全偏置。
3. 对曲率变化大的边缘区域，应提高候选视点密度和图像重叠率。
4. 可借鉴“偏差验证后增加路径线”的思想，转化为“覆盖不足后补拍”。

最适合形成本文创新的转化：

```text
残留高度约束 -> 有效覆盖率约束
刀具偏置曲面 -> 内窥镜安全观测偏置面
加工精度验证 -> 图像质量与覆盖率验证
```

### 1.4 金属表面异形区域上色轨迹自动规划

可借鉴点：

1. 从图像中自动提取异形区域。
2. 使用二值化、Canny边缘检测和轮廓点排序提取目标轮廓。
3. 使用Bezier曲线对轮廓进行偏置和插值。
4. 使用等弦长离散确定轨迹点位置。

迁移到本项目：

1. 对叶片某些可见ROI，可先提取区域轮廓，再做内缩/外扩偏置。
2. 叶尖、阻尼台等局部区域可用轮廓环扫或等弦长离散生成候选视点。
3. 图像平面ROI到机器人拍照点的生成可借鉴“区域提取-轮廓排序-偏置-离散”的流程。

最适合写进候选视点生成模块：

```text
ROI轮廓提取 -> 轮廓偏置 -> 等弦长候选视点离散
```

## 2. 可作为背景与综述支撑的文献

### 2.1 印花面料的边缘轮廓快速提取方法

可借鉴点：

1. 深度学习分割与传统轮廓检测结合。
2. 用形态学去除边缘毛刺干扰。
3. Canny算子提取边缘轮廓。
4. 轮廓结果为后续机器人轨迹规划提供坐标信息。

迁移到本项目：

1. 外部相机识别叶片边缘时，可采用“分割+形态学+轮廓提取”的技术路线。
2. 可支撑本文中“视觉定位结果为轨迹规划提供几何先验”的论述。

### 2.2 基于轮廓提取的缝纫机器人运动轨迹规划研究进展

可借鉴点：

1. 将机器视觉轮廓提取和机器人轨迹优化作为两大核心技术。
2. 综述了Canny、形态学、水平集等轮廓提取方法。
3. 强调轮廓精度会直接影响机器人运动轨迹质量。

迁移到本项目：

1. 可用于第一篇引言和相关工作部分。
2. 可支撑“视觉定位精度影响路径规划质量”的论述。

### 2.3 六自由度切削机器人在复杂曲面加工中轨迹规划研究

可借鉴点：

1. B样条插补用于复杂曲面轨迹平滑。
2. 关注末端位姿、进给速度、关节角和角速度平稳过渡。
3. 通过仿真验证机器人运动平稳性。

迁移到本项目：

1. 可作为底层运动轨迹平滑与机器人执行验证的参考。
2. 不建议作为本文主方法，因为它更偏连续轨迹插补，不解决主动视点选择。

### 2.4 基于叶片几何特征的精加工刀具轨迹生成

可借鉴点：

1. 根据叶片几何特征计算步长和行距。
2. 将加工质量指标转化为轨迹优化目标。
3. 采用分段优化降低整体优化难度。
4. 通过参数协同优化提高复杂曲面加工稳定性。

迁移到本项目：

1. 可将“切削力稳定”类比为“图像质量稳定”。
2. 可将“几何特征决定步长和行距”转化为“曲率和ROI尺度决定候选视点间距”。
3. 可将“分段优化”转化为“按叶尖、边缘、曲面、阻尼台分区决策”。

## 3. 对第一篇算法设计的直接启发

### 3.1 候选视点生成

建议吸收以下方法：

1. 等截平面法：用于叶盆、叶背曲面区域生成扫描线。
2. 等弧长/等弦长离散：用于边缘和轮廓候选视点采样。
3. 曲率自适应步长：曲率大处视点更密，曲率小处视点更稀。
4. 偏置曲面/偏置曲线：沿局部法向生成内窥镜安全工作距离。
5. 轮廓排序与轮廓偏置：用于叶尖、阻尼台等局部异形区域。

### 3.2 优化目标设计

加工类论文通常优化加工质量、残留高度、切削力或轨迹平滑性。本文应将其转化为视觉检测目标：

```text
加工残留高度 -> 拍照有效覆盖率
切削力波动 -> 图像质量波动
刀具磨损风险 -> 内窥镜碰撞/姿态突变风险
轨迹长度 -> 检测节拍
轨迹平滑性 -> 末端拍照稳定性
```

### 3.3 强化学习切入点

这些文献多数采用确定性轨迹生成、离线规划或传统优化，没有解决以下问题：

1. 当前已经拍到哪些区域。
2. 哪些图像质量不合格。
3. 下一步去哪个视点收益最大。
4. 是否需要局部补拍。
5. 如何在覆盖率、图像质量、运动代价之间动态取舍。

这正好是本文采用Maskable PPO的理由。论文中可以写：

```text
现有轨迹规划方法多基于几何模型或离线优化生成固定轨迹，难以根据实时图像质量和覆盖状态调整后续拍照动作。为此，本文将多部位拍照过程建模为质量约束下的序贯视点选择问题，并采用Maskable PPO进行主动视点决策。
```

## 4. 最终建议

第一篇不是简单做“机器人轨迹规划”，而应写成：

```text
外部视觉引导下基于强化学习的转子叶片多部位主动拍照视点规划
```

文献借鉴关系可以这样组织：

1. 视觉定位和轮廓提取：借鉴机器人打磨、缝纫机器人和异形区域上色文献。
2. 曲面与边缘候选路径：借鉴风电叶片点云、近净成形叶片和叶片刀具轨迹文献。
3. 底层运动平滑：借鉴六自由度切削机器人轨迹插补文献。
4. 本文创新：把固定轨迹生成升级为基于强化学习的主动视点选择和质量反馈补拍。

建议后续在算法设计中固定如下结构：

```text
外部视觉粗定位
-> ROI轮廓/曲面特征提取
-> 曲率自适应候选视点生成
-> Maskable PPO主动视点选择
-> RRTConnect/MoveIt连接相邻视点
-> 图像质量评价与补拍
```

第一优先引用：

1. 近净成形叶片重构曲面刀具轨迹自适应规划
2. 基于三维点云的风电叶片飞边残留量检测与机器人打磨路径规划
3. 基于视觉定位与轨迹规划的机器人打磨工作站
4. 金属表面异形区域上色轨迹自动规划

第二优先引用：

1. 基于叶片几何特征的精加工刀具轨迹生成
2. 印花面料的边缘轮廓快速提取方法
3. 基于轮廓提取的缝纫机器人运动轨迹规划研究进展
4. 六自由度切削机器人在复杂曲面加工中轨迹规划研究

## 6. 不建议过度借鉴的地方

1. 不建议把加工残留高度、切削力模型直接写成本文核心，因为本文不是加工论文。
2. 不建议把打磨路径直接改名为拍照路径，因为二者优化目标不同。
3. 不建议把Canny、B样条、Bezier等传统方法包装成主要创新，它们更适合作为候选视点生成的基础工具。
4. 不建议让强化学习直接输出连续六维机器人位姿，第一阶段应让强化学习在候选视点集合中做离散决策。

## 7. 对当前第一篇的具体修改方向

建议将现有第一篇算法路线进一步修改为：

```text
第1层：外部相机粗定位
第2层：基于轮廓/曲率/偏置曲面的候选视点生成
第3层：基于Maskable PPO的主动视点选择
第4层：RRTConnect/MoveIt可执行轨迹连接
第5层：图像质量反馈补拍
```

其中第2层主要借鉴现有文献，第3层和第5层作为本文主要创新。
