# 候选拍照视点生成使用说明

本步骤对应论文方法中的“基于 ROI 轮廓/曲率/视场约束的候选拍照视点生成”。输入来自第一步的三维表面点特征，输出为相机或末端内窥镜的候选拍摄位姿。

## 1. 输入文件

主要输入是第一步生成的点级曲面特征：

```text
outputs\blade_surface_point_features.csv
```

该文件包含：

```text
x, y, z, nx, ny, nz, curvature, roughness, boundary_score, boundary_flag
```

其中 `x,y,z` 是表面点坐标，`nx,ny,nz` 是局部表面法向量，`curvature` 是曲率，`boundary_flag` 是 ROI 边界候选点标记。

## 2. 生成候选拍照视点

在 Windows 命令提示符中运行：

```cmd
cd /d E:\graduation_paper\trajectory_planning
python .\scripts\generate_candidate_viewpoints.py --point-features-csv ".\outputs\blade_surface_point_features.csv" --output-csv ".\outputs\candidate_viewpoints\blade_candidate_viewpoints.csv" --output-json ".\outputs\candidate_viewpoints\blade_candidate_viewpoints_summary.json" --working-distance 20 --hfov-deg 55 --vfov-deg 40 --overlap 0.35 --max-views 160
```

输出文件：

```text
outputs\candidate_viewpoints\blade_candidate_viewpoints.csv
outputs\candidate_viewpoints\blade_candidate_viewpoints_summary.json
```

## 3. 可视化候选视点

```cmd
cd /d E:\graduation_paper\trajectory_planning
python .\scripts\visualize_candidate_viewpoints.py --viewpoints-csv ".\outputs\candidate_viewpoints\blade_candidate_viewpoints.csv" --point-features-csv ".\outputs\blade_surface_point_features.csv" --output-dir ".\outputs\candidate_viewpoints\visualization" --max-background-points 20000 --max-viewpoints 160
```

输出图片：

```text
outputs\candidate_viewpoints\visualization\candidate_viewpoints_3d.png
outputs\candidate_viewpoints\visualization\candidate_viewpoints_top_projection.png
```

## 4. 关键参数含义

`--working-distance`：相机或内窥镜到叶片表面的工作距离。单位与 STL/点云单位一致。

`--hfov-deg`：水平视场角。

`--vfov-deg`：垂直视场角。

`--overlap`：相邻视点之间的期望重叠率。越大，视点越密。

`--max-views`：最多保留多少个候选视点。该值不是最终拍照数量，而是后续路径优化或强化学习选择动作空间。

`--normal-orientation`：法向量方向修正方式。默认 `away_from_centroid`，表示相机放在远离叶片点云中心的一侧，避免候选点落入模型内部。

`--sampling-strategy`：采样策略。默认 `stratified`，表示分层自适应采样；可选 `priority`，表示完全按曲率/边界优先级选点。

## 5. 当前默认方法

当前实现采用分层自适应候选视点生成：

```text
1. 根据工作距离和视场角计算单视点理论覆盖范围。
2. 根据曲率、边界分数和粗糙度计算点级优先级。
3. 将点分为 boundary_high_curvature、boundary、high_curvature、surface 四类。
4. 对四类区域进行分层配额采样，避免候选点全部集中在边界。
5. 沿修正后的表面法向量偏置工作距离，生成相机位置。
6. 将相机光轴指向对应表面点，输出候选拍摄位姿。
```

核心位姿生成关系：

```text
camera_position = surface_point + working_distance * normal
view_direction = -normal
```
