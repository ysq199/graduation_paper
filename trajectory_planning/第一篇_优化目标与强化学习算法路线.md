# 第一篇论文优化目标与强化学习算法路线

## 0. 论文任务边界

第一篇论文只解决“怎么让机器人围绕压气机转子叶片稳定、高质量、少冗余地拍照”的问题，不展开YOLO缺陷检测网络改进。第二篇论文再利用第一篇采集到的图像，研究转子叶片缺陷检测算法。

第一篇的核心问题定义为：

```text
外部相机粗定位条件下，面向叶片多检查部位的质量约束主动视点规划问题。
```

更具体地说，机器人末端内窥镜需要在叶尖、进气边、排气边、叶盆、叶背和阻尼台等区域选择一系列拍照视点，使采集图像满足缺陷检测需要，同时尽量减少拍照点数量、运动距离和检测时间。

## 1. 总体算法路线

推荐采用以下组合，而不是让强化学习承担全部机器人规划任务：

```text
外部相机粗定位
+ 多检查部位参数化候选视点生成
+ Maskable PPO选择下一最佳拍照视点
+ RRTConnect/MoveIt连接相邻视点
+ 图像质量反馈补拍
```

其中，各模块分工如下：

1. 外部相机粗定位：确定转子中心、初始叶片、当前分度角、目标叶片编号和待检区域粗位置。
2. 参数化候选视点生成：根据不同部位几何特征生成有限候选视点集合。
3. Maskable PPO视点选择：根据当前覆盖状态、图像质量状态和机器人当前位置，选择下一最佳拍照视点。
4. RRTConnect/MoveIt局部运动规划：负责相邻视点之间的避障运动，不作为论文主要创新点。
5. 质量反馈补拍：对反光、虚焦、遮挡和覆盖不足区域触发再次决策与局部补拍。

这种结构的优点是：候选视点由工程几何知识保证可解释性，强化学习负责复杂序贯决策，底层运动由成熟规划器保证可执行性。

## 2. 优化目标

第一篇的优化目标不应只写“路径最短”，而应围绕视觉检测任务展开。

### 2.1 硬约束

1. 有效覆盖率约束：

```text
C_eff(R_k) >= C_min
```

其中，`R_k` 为第 `k` 个检查部位，`C_eff` 为有效覆盖率。只有满足工作距离、视角、清晰度和曝光要求的覆盖才计入有效覆盖。

2. 工作距离约束：

```text
d_min <= d_i <= d_max
```

其中，`d_i` 为第 `i` 个视点到目标表面的距离。

3. 观测角度约束：

```text
theta_i <= theta_max
```

其中，`theta_i` 为相机光轴与局部表面法向之间的夹角。

4. 图像重叠率约束：

```text
rho_i >= rho_min
```

用于保证相邻图像之间有足够重叠，避免漏拍。

5. 机器人可达性与避碰约束：

```text
p_i in W_robot
Collision(p_i) = false
```

其中，`W_robot` 为机器人可达工作空间。

### 2.2 综合目标函数

建议将目标函数定义为：

```text
min J = w1(1 - C_eff) + w2(1 - Q_img) + w3N + w4L + w5R
```

其中：

1. `C_eff`：有效覆盖率。
2. `Q_img`：图像质量评分。
3. `N`：拍照点数量。
4. `L`：机器人总运动路径长度或执行时间。
5. `R`：风险惩罚项，包括碰撞风险、奇异位形、定位误差敏感性和末端姿态突变。

该目标函数的论文表达重点是：路径规划服务于后续缺陷检测，因此优化目标从几何最短路径扩展为质量约束下的有效拍照覆盖。

## 3. 候选视点生成

强化学习不直接在连续六维位姿空间中搜索，而是在参数化模板生成的候选视点集合中选择动作。这样可以降低训练难度，也更容易满足机器人安全约束。

### 3.1 叶尖

叶尖采用短弧线或横向线扫候选视点。

```text
V_tip = {v_tip,1, v_tip,2, ..., v_tip,n}
```

主要约束是叶尖区域完整覆盖、视点间重叠和端部缺陷分辨率。

### 3.2 进气边与排气边

进气边和排气边采用边缘跟随候选视点。设边缘中心线为 `e(s)`，候选视点为：

```text
v(s) = e(s) + d n(s)
```

其中，`n(s)` 为观测偏置方向，`d` 为工作距离。

### 3.3 叶盆与叶背

叶盆和叶背采用曲面往复覆盖候选视点。设曲面为 `S(u, v)`，候选视点为：

```text
v(u_i, v_j) = S(u_i, v_j) + d n(u_i, v_j)
```

视点间距由内窥镜视场、表面曲率和图像重叠率决定。

### 3.4 阻尼台

阻尼台采用环扫与局部侧扫结合：

```text
V_damper = V_outer U V_inner U V_side
```

其中，`V_outer` 覆盖外缘，`V_inner` 覆盖内缘，`V_side` 覆盖侧面和转接圆角。

## 4. 强化学习建模

### 4.1 方法选择

推荐使用：

```text
Maskable PPO
```

原因是：候选视点集合中会存在不可达、碰撞、已访问或当前阶段不允许选择的动作，需要通过动作掩码屏蔽。相比普通PPO和DQN，Maskable PPO更适合这种带约束的离散动作选择任务。

### 4.2 状态空间

状态 `s_t` 建议包含：

```text
s_t = {x_robot, M_cov, M_quality, F_view, b_part, n_step}
```

其中：

1. `x_robot`：当前机器人末端位姿或当前视点编号。
2. `M_cov`：各待检区域覆盖状态。
3. `M_quality`：已采集图像质量状态，包括清晰度、曝光、反光和目标居中程度。
4. `F_view`：候选视点特征，包括覆盖贡献、运动代价、可达性、安全裕量和预计质量。
5. `b_part`：当前检测部位类型。
6. `n_step`：已拍照次数或剩余预算。

### 4.3 动作空间

动作定义为选择下一个候选拍照视点：

```text
a_t in {1, 2, ..., N_view}
```

通过动作掩码 `mask_t` 屏蔽以下视点：

1. 不可达视点。
2. 碰撞风险视点。
3. 工作距离不满足约束的视点。
4. 视角不满足约束的视点。
5. 已访问且没有新增覆盖收益的视点。

### 4.4 奖励函数

奖励函数建议定义为：

```text
r_t = alpha * Delta C_eff
    + beta  * Delta Q_img
    - gamma * Delta L
    - eta   * N_shot
    - mu    * O_repeat
    - lambda * P_risk
```

其中：

1. `Delta C_eff`：本次拍照带来的有效覆盖率增益。
2. `Delta Q_img`：图像质量增益。
3. `Delta L`：从上一视点到当前视点的运动代价。
4. `N_shot`：拍照次数惩罚。
5. `O_repeat`：重复覆盖惩罚。
6. `P_risk`：碰撞、奇异位形、姿态突变和定位误差敏感性惩罚。

奖励函数的核心思想是鼓励智能体选择“新增有效覆盖多、图像质量好、运动代价低、安全裕量高”的视点。

### 4.5 终止条件

回合终止条件建议设置为：

1. 所有待检区域有效覆盖率达到阈值。
2. 已达到最大拍照次数。
3. 连续若干步没有新增有效覆盖。
4. 任务无法继续执行。

## 5. RRTConnect/MoveIt的作用

强化学习只决定下一个拍照视点，不直接负责机械臂连续运动轨迹。两个视点之间的实际运动由RRTConnect或MoveIt完成。

论文中可以这样表述：

```text
强化学习输出离散拍照视点序列，底层运动规划器根据机器人运动学和碰撞约束生成相邻视点之间的可执行轨迹。
```

这样处理有两个好处：

1. 降低强化学习训练难度。
2. 保证机器人运动规划结果具有工程可执行性。

## 6. 图像质量反馈补拍

首轮拍照后，系统对每张图像进行质量评价。若某区域存在反光、虚焦、遮挡或覆盖不足，则将该区域重新加入待拍集合，并更新状态：

```text
M_cov, M_quality -> M_cov', M_quality'
```

随后由Maskable PPO继续选择补拍视点。补拍策略不重复整段路径，而是局部决策、局部补拍。

这部分可作为第一篇的重要创新点，名称可写为：

```text
基于质量反馈的主动补拍机制
```

## 7. 可对比基线

后续实验至少需要设置以下基线：

1. 固定示教视点。
2. 贪心视点选择。
3. 遗传算法视点排序。
4. 无质量反馈补拍。
5. 本文Maskable PPO主动视点规划。

其中，遗传算法不再作为主方法，而是作为对比基线。这样既能解释为什么不用遗传算法，又能证明强化学习的优势。

## 8. 评价指标

建议第一篇围绕以下指标做实验：

1. 有效覆盖率 `C_eff`。
2. 普通几何覆盖率 `C_geo`。
3. 有效图像率 `Q_valid`。
4. 拍照点数量 `N`。
5. 总运动路径长度 `L`。
6. 单片叶片检测时间 `T`。
7. 首次接近成功率。
8. 补拍触发次数。
9. 覆盖不足区域比例。
10. 运动规划成功率。

其中，最重要的是 `C_eff`、`Q_valid`、`N` 和 `T`，这四个指标直接体现论文方法价值。

## 9. 论文创新点定位

第一篇的创新点建议固定为三条：

1. 提出外部视觉引导下的转子叶片多部位候选视点参数化生成方法。
2. 将多部位拍照路径规划建模为质量约束主动视点选择问题，并采用Maskable PPO实现受约束视点决策。
3. 提出基于图像质量反馈的局部补拍机制，提高高反光、遮挡和复杂曲面区域的有效覆盖率。

## 10. 接下来的实现步骤

建议按以下顺序推进：

1. 明确候选视点的数据结构。
2. 建立简化仿真环境：用ROI网格模拟叶片区域，用候选视点覆盖若干网格。
3. 实现有效覆盖率和图像质量评分函数。
4. 实现贪心基线算法。
5. 实现Maskable PPO环境接口。
6. 训练并对比Maskable PPO与贪心、遗传算法、固定示教方案。
7. 再接入真实机器人或MoveIt/RRTConnect运动规划。

当前优先完成第1步：定义候选视点数据结构和有效覆盖率计算方式。
